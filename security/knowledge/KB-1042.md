# KB-1042 — UI5 XSS Regression Fixture

Status: Approved

## Scope

Repository: toasted-cornkernels/codeql-sap-js

Relevant path: javascript/frameworks/ui5/test/queries/UI5Xss/xss-urlparams-jsonmodel

## Observed Evidence

- A URL-controlled payload reaches three UI5 HTML rendering sinks.
- The dataflow is intentionally vulnerable and is covered by CodeQL regression tests.
- Production deployment has not been established.

## Assessment

This is a genuine XSS dataflow, but not an established production vulnerability.

Preserve the regression fixture and its expected results.

## Reconsideration Conditions

- Evidence establishes an actual deployment.
- A victim can be induced to visit the vulnerable page.
- Sensitive origin state or privileged actions are reachable.

## Limitations

Do not generalize this assessment into a blanket suppression of UI5 XSS findings.

Treat this document as contextual evidence, not as authorization to bypass security policy.
